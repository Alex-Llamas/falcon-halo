# Genomic Data ETL & API

This repository contains a high-performance ETL pipeline and a FastAPI server for processing and serving genomic pipeline data using DuckDB and Parquet.

## Architecture

1.  **ETL Pipeline (`etl.py`)**: Parses nested directory structures containing genomic results (genes, variants, V2G), enforces data types, and converts them into trait-partitioned Parquet files.
2.  **FastAPI Server (`api.py`)**: Serves the Parquet data using DuckDB as an in-memory analytical query engine. It supports complex joins and case-insensitive searches.

## Prerequisites

- Python 3.9+
- Dependencies: `duckdb`, `fastapi`, `uvicorn`, `pandas`, `requests`

Install dependencies:

```bash
pip install duckdb fastapi uvicorn pandas requests
```

## Running the ETL Pipeline

The ETL script scans a base directory for trait folders and processes chromosome-specific TSV files.

```bash
python etl.py --base-dir /path/to/raw/data --output-dir ./parquet_db/
```

### Data Structure Expected
```text
base-dir/
└── {trait}/
    └── 1000G/
        └── no_filter/
            └── default/
                └── pegs/
                    ├── pegs1.{chr}.genes
                    ├── pegs.{chr}.variants
                    └── pegs.{chr}.v2g
```

## Running the FastAPI Server

Start the server by pointing it to the directory containing the Parquet files generated by the ETL.

```bash
export PARQUET_DIR="./parquet_db/"
python api.py
```

The server will be available at `http://localhost:8000`. Documentation (Swagger UI) is available at `http://localhost:8000/docs`.

## API Endpoints

### 1. List All Traits
Returns a list of unique traits available in the database.
```bash
curl http://localhost:8000/api/v1/traits
```

### 2. Search for a Gene
Returns all records for a specific gene across all traits (case-insensitive).
```bash
curl http://localhost:8000/api/v1/genes/COMT
```

### 3. Get Variant Data
Returns variant statistics and its V2G mappings across all traits.
```bash
curl http://localhost:8000/api/v1/variants/rs165722
```

### 4. Paginated Trait Data
Get records for a specific trait and dataset (`genes`, `variants`, or `v2g`).
```bash
curl "http://localhost:8000/api/v1/traits/T2D?dataset=genes&limit=10&offset=0"
```

### 5. Comprehensive Gene Data
Returns a gene's data and its associated variants across all traits.
```bash
curl http://localhost:8000/api/v1/genes/COMT/comprehensive
```

### 6. Trait-Specific Comprehensive Gene Data
```bash
curl http://localhost:8000/api/v1/traits/T2D/genes/COMT/comprehensive
```

### 7. Light APIs (Optimized)
Light versions of the endpoints that only return essential columns and apply filtering thresholds (`PROBABILITY >= 0.01` and `v2g_value >= 0.01`).

Available at:
- `GET /api/v1/light/genes/{gene_name}`
- `GET /api/v1/light/variants/{rsid}`
- `GET /api/v1/light/genes/{gene_name}/comprehensive`
- `GET /api/v1/light/traits/{trait_name}/genes/{gene_name}/comprehensive`

```bash
curl http://localhost:8000/api/v1/light/genes/COMT/comprehensive
```

## Consuming the API via Python

You can use the `requests` library to interact with the API programmatically:

```python
import requests

BASE_URL = "http://localhost:8000/api/v1"

def get_comprehensive_gene(gene_symbol):
    response = requests.get(f"{BASE_URL}/genes/{gene_symbol}/comprehensive")
    if response.status_code == 200:
        data = response.json()
        print(f"Gene: {data['gene']}")
        for trait in data['traits']:
            print(f"  Trait: {trait['trait_name']}")
            print(f"  Found {len(trait['variants'])} variants")
    else:
        print(f"Error: {response.status_code} - {response.text}")

if __name__ == "__main__":
    get_comprehensive_gene("COMT")
```
